> **배점 단일 기준**: `config.COMPONENT_MAX`. 영역 합계(`AREA_MAX`)와 총점(`TOTAL_MAX`)은
> 여기서 자동 계산되며, 화면·엑셀 헤더·설명 화면 표기도 모두 이 값에서 생성된다.
> 현재 총점 **100점** (권리 27 · 기술 21 · 시장 27 · 영향력 25 / 정량 84 : LLM 16).
> 세부 산출식과 구간표는 앱의 `? 설명` 탭에서 항상 최신 상태로 확인할 수 있다
> (설명 화면이 배점 상수에서 생성되므로 이 문서보다 우선한다).

`python-lib/primepatent/scoring/` 구현과 1:1로 대응합니다.
배점 상한은 `config.COMPONENT_MAX` 에서 강제되므로 어떤 경우에도 세부지표가 배점을 초과하지 않습니다.

## 0. 공통 규칙

| 규칙 | 구현 |
|---|---|
| 국가 커버리지 | `records.family_country_sources()` — 개별국 문헌 수 → 패밀리 문헌번호 → 자국 순. **지정국 코드는 제외**(실제 출원이 아님) |
| 출원인 표준화 | `applicants.cluster_applicants()` — 사용자가 **승인**한 표준명만 `records.build_records(applicant_map=...)` 로 반영. 승인 전에는 원본 표기 사용 |
| 패밀리 대표문헌 | `family.build_families()` — 상태 우선순위 → 국가 우선순위 → 청구항 수 → 피인용 → 이른 우선일 |
| 비교집단 | `peers.PeerIndex.rank()` — `Topic+연도` → `Topic+연도±N` → `Topic` → 전체, 표본 부족 시 중립 0.5 |
| 비교집단 모집단 | **채점 단위(패밀리 대표문헌)**. 전체 문헌으로 구성하면 다국 출원 패밀리가 분포를 지배해 백분위가 왜곡된다 |
| 백분위 | `peers.percent_rank_inc()` = 엑셀 `PERCENTRANK.INC` = (자신보다 작은 값 수)/(n-1) |
| 비교집단 분포 | `peers.PeerIndex.stats()` — 최소/25%/중앙/75%/최대/평균(엑셀 `PERCENTILE.INC` 정의). 결과 상세 화면에 함께 표시된다 |
| 모집단 최대값 비율 | `AnalysisContext.max_ratio()` — 외부TR·TR 은 백분위가 아니라 `(값 ÷ 채점 대상 최대값)` 을 쓰고 1.0 으로 상한을 둔다 |
| 기준일 | 설정 `as_of_date`, 미지정 시 실행일 |

## 1. 권리 중요도 30

### 1.1 권리 생존성 8 (`rights.survival`)
`status.classify()` 가 상태정보/DOCDB 법적상태/등록서지로 상태를 판정합니다.

| 상태 | 점수 |
|---|---|
| 등록·존속 | 8 |
| 등록·만료임박(잔존 2년 이하) | 6 |
| 공개·심사중 | 5 |
| 출원(심사 미청구) | 3 |
| 등록 후 소멸·포기 | 2 |
| 상태 미상 | 2 |
| 거절·취하·포기 / 무효 확정 | 0 |

### 1.2 청구범위 강도 8 (`rights.claimScope`)
- 정량 4점 = `2 × 독립항수 백분위 + 2 × 청구항수 백분위`
- LLM 4점 = 대표/독립청구항의 권리범위 넓이 (필수 구성요소 수, 수치·재료·공정 한정,
  기능적 표현, 복수 카테고리 독립항, 회피 가능성 종합)

### 1.4 잔존기간 4 (`rights.remainingTerm`)
만료일 컬럼이 있으면 그 값, 없으면 `최초우선일 + 20년`.
`≥12년 → 4점 / ≥8 → 3 / ≥4 → 2 / >0 → 1 / 만료 → 0`
잔존기간은 제도상 상한(20년)으로 제한한다(우선일이 미래로 잘못 기재된 행 방어).

### 1.5 권리유지·방어 신호 3 (`rights.defenseSignal`)
분할·연속출원 1 + 심판·소송 1 + 양도 또는 실시권 1 (패밀리 단위 신호).
컬럼 자체가 없으면 0점 처리하고 `missingSignals` 로 구분 표기합니다.

## 4. 영향력·경쟁성 25 (`scoring/impact.py`)

| 세부지표 | 배점 | 산출 |
|---|---|---|
| 경쟁사 커버리지 | 7 | `(대상 건의 외부TR ÷ 모집단 외부TR 최대값) × 7` |
| 연령보정 피인용 영향력 | 13 | `(대상 건의 TR ÷ 모집단 TR 최대값) × 13` |
| 기술 선도성 | 5 | `(1 − 동일주제 최초우선일 백분위) × 5` |

> **모집단 최대값**은 백분위 비교집단과 같은 단위, 즉 **채점 대상(패밀리 대표문헌)** 에서 구합니다
> (`AnalysisContext._build_metric_max`). 전체 문헌으로 잡으면 중복 제거된 패밀리 구성원이
> 최대값을 만들어 채점 단위와 어긋납니다.
>
> - 외부TR / TR 값이 비어 있으면 **0점**으로 처리하고 결과 상세에 사유를 남깁니다(숨기지 않음).
> - 모집단 최대값이 0이면(모두 결측·0) 비율을 만들 수 없으므로 전 건 0점이며, 역시 사유를 남깁니다.
> - 비율은 1.0 으로 상한을 둡니다(음수·이상값 방어).
> - 결과 상세에는 `value / populationMax / ratio / populationN / formula` 가 그대로 표시됩니다.
